📋 核心技术亮点与工程取舍

1. 边缘算力解耦与轻量化通信：针对 Arduino UNO 算力受限的问题，实现视觉任务完全下沉至 MaixCAM-Pro。通过置信度阈值过滤后，仅向下位机发送 `0, 1, 2` 三个离散控制指令，大幅降低通信带宽与主控负载。

2. 多帧滑动窗口多数表决（抗抖动）：针对赛场环境震动与光线波动引起的单帧误检，采用滑动窗口机制（连续收集 10~15 帧识别结果，取类别众数）进行时序平滑去噪，大幅提升系统稳定性。

3. 应用层冗余通信策略（抗丢包）：鉴于 3.3V 与 5V 电平转换模块可能引起的串口偶发丢包，设计应用层冗余策略，单次决策连续重复发送 10~20 次相同指令，以极小开销确保下位机状态机永不卡死。

4. 置信度兜底与实用化推理：设定置信度 0.78 为拒识阈值，并针对三棱柱置信度偏低的情况，采用“非高置信度默认归类为三棱柱”的兜底逻辑，确保比赛全流程稳定输出。

5. 系统级方案取舍：初期尝试复用视觉定位盒子失败（资源竞争+视觉畸变），果断战略性放弃，改用超声波标定停车点。贯彻“工程落地优先级高于理论完美”的研发准则。
